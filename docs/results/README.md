# Results files

Measured results live here, as files that contain **counts, rates and ids only** (no chat text, no titles, summaries or quotes). They are produced by commands, not typed:

| file | produced by | what it holds |
|---|---|---|
| `eval_full_A.json`, `eval_full_A.md` | `python -m gcw evaluate CHAT --aliases aliases.example.json --truth synthetic/frozen/ground_truth.json --phase 4a --out docs/results/eval_full_A` | three full-chat runs of config A (prompt v1): usage, cost, verification rates and drop reasons, items kept, strict / lenient recall per planted id, by third of the chat and dev versus held-out, unplanted counts, title and summary length distributions |
| `injection_probe.md` | recorded by hand from the run logs of 2026-11-06 | the prompt-injection probe: number of attempts and how many were obeyed |

## Rules

1. **Every number in the project README must cite a results file** in this folder (design constants such as font sizes and character limits are specified in `docs/PRD.md` and configuration defaults in `--help`; they are not results).
2. **Costs are computed from the `usage` fields of each response times the list prices** in `docs/api-notes.md` (rows 14 and 15; a request over 100,000 prompt tokens is billed whole at the high tier), **unless a Console reconciliation is recorded** in this folder. No reconciliation has been recorded yet, so all costs here are computed, not reconciled.
3. Results are reported as n, mean and range. No ranking of configurations, no winner language, and no claim beyond the synthetic frozen chat that was measured.
4. A results file is regenerated by its command; do not edit it by hand (except `injection_probe.md`, which says it is hand-recorded and where from).
5. The blind rating pack (`out/rating/`, gitignored) is not a results file: its ratings, once made by a person, are summarised here as counts only.
